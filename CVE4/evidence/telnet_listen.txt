Note
----
`GetValue("lan.ip")` reads bare NVRAM backed by flash. In this emulation the NVRAM
value is empty, so the HTTP request path was not closed end-to-end; the same
`doSystemCmd("telnetd -b %s &")` command was executed directly. The HTTP entry point
is established statically. On physical hardware, `GET /goform/telnet` is the first
verification point.
